# @supertiny99/dsh-plugin-guardian

DeepSeek Harness（桌面版）插件管家与防灾恢复工作台：解决第三方插件发生致命异常后宿主全盘禁用的痛点，提供自动健康快照、一键勾选恢复、配置挽回与跨平台桌面脱机应急恢复脚本。

---

## 解决的核心痛点

在 DSH 开发或安装第三方插件时，若某个插件发生致命异常导致宿主启动崩溃，DSH 官方的致命错误恢复机制（`sanitizeProfile`）会一刀切**将所有第三方插件全部移出激活列表**，并将用户配置文件重命名为 `cordis.patch.yml.bak-<时间戳>`。

这导致用户重启后：
1. **记忆负担重**：必须回忆崩溃前到底开启了哪几个插件；
2. **操作繁琐**：必须在插件列表里逐一翻找并手动重新点击开启；
3. **二次闪退风险**：若不慎又开启了刚才引发崩溃的异常插件，会再次闪退；
4. **配置丢失**：用户自定义的模型与参数配置被归档为 `.bak`，当前变为纯空配置。

## 插件管家核心能力

1. **自动健康快照**：
   - 每次 DSH 正常启动及运行时，自动在本地维护健康快照（记录 `bundles` 顺序与完整配置）；
   - 内置智能防膨胀机制（最大保留 20 份自动轮转，单份仅约 1~14 KB，支持手动删除与一键清理）。
2. **事故高亮预警与一键恢复**：
   - 遭遇崩溃清空后，用户**只需在官方插件页开启【插件管家】这 1 个插件**；
   - 进入插件管家面板，页面将弹出醒目告警横幅，列出被停用的全部插件清单；
   - 支持**「一键全量恢复」**瞬间复原所有插件。
3. **排除特定坏插件（隔离排错）**：
   - 支持多选框取消勾选可疑插件，只恢复其余稳定插件，避免陷入死循环崩溃。
4. **用户配置（.bak）智能挽回**：
   - 自动扫描被官方重命名的 `cordis.patch.yml.bak` 文件，支持一键对比并覆盖还原。
5. **跨平台脱机应急脚本（双击秒级恢复）**：
   - 自动在 Profile 目录生成（并支持一键导出到桌面）免依赖的应急脚本：
     - **Windows**：`restore-plugins.bat`（原生批处理）
     - **macOS**：`restore-plugins.command`（原生终端脚本）
   - DSH 彻底打不开时，直接在桌面双击该脚本，1 秒钟在后台脱机复原。

## 安装方式

在 DSH 桌面版「设置/侧栏 → 插件 → 添加插件」，任选一种 spec 安装：

### 1. npm 渠道（推荐）

```
@supertiny99/dsh-plugin-guardian
```

### 2. GitHub 渠道（源码安装，tag 定版本）

```
github:supertiny99/dsh-plugin-guardian#v0.1.1
```

### 3. 本地 tarball 离线安装

下载 release 的 `.tgz` 包后，在输入框填写本地绝对路径：

```
file:/你的绝对路径/supertiny99-dsh-plugin-guardian-0.1.1.tgz
```

> **注意**：安装后请完全退出 DSH 桌面应用并重新打开（冷启动），左侧栏即可出现 **🛡️ 插件管家** 图标。

## 技术规范与安全性

- **零外呼、零第三方重依赖**：纯本地读写 `~/.dsh/profiles/desktop/` 相关配置文件；
- **原子级写保护**：修改 `package.json` 与 `cordis.patch.yml` 均采用临时文件重命名（atomic rename），杜绝半写损坏；
- **UI 规范**：严格遵循 DSH `ui-style-guide`，样式全走 `--dsw-alias-*` token，全矢量 SVG 图标（无 emoji），完美自适应明暗主题；
- **构建规范**：产物仅约 20 KB，经本地沙箱 `selfcheck` 预检，确保不会拖垮宿主。
